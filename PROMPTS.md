# PROMPTS.md - HBD My Love ❤️

## Project Description

This is a romantic birthday surprise website built with Next.js, Tailwind CSS, and Framer Motion.
The website features multiple interactive sections including an opening surprise, birthday celebration,
photo gallery, love letter, reasons why I love you, birthday wishes, and a grand finale.

## Design Concept

- **Theme**: Romantic, premium, aesthetic
- **Colors**: Soft pink, cream, white, rose accents
- **Effects**: Glassmorphism, gradient backgrounds, floating hearts, sparkle stars
- **Typography**: Inter for body, Dancing Script for decorative text
- **Animations**: Framer Motion for smooth transitions and interactions

## Content Management

All content is managed through `lib/data-konten.js` - edit this single file to customize
the entire website without touching any components.
